# Sanrio Sweet Cafe

Sanrio Sweet Cafe is a Java-based shopping application with a cute, cafe-inspired theme. It allows users to browse products, manage a shopping cart, enter customer information, and select shipping options through a terminal-based interface.

## Features

- **Product Catalog:** Browse available products.
- **Shopping Cart:** Add items and manage shopping selections.
- **Customer Information:** Handle customer details.
- **Shipping Options:** Select from available shipping methods.
- **Terminal Colors:** Use colored terminal output to improve the user experience.
- **Command-Line Interface:** Interact with the shopping application directly through the terminal.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Command-Line Interface (CLI)
- Git and GitHub

## How to Run

### Prerequisites

- Install the Java Development Kit (JDK).
- Ensure Java is available from your terminal.

### Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/Layali-Shk/Sanrio-Sweet-Cafe.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Sanrio-Sweet-Cafe
   ```

3. Compile the Java source files:

   ```bash
   javac -d out src/*.java
   ```

4. Run the application:

   ```bash
   java -cp out Main
   ```
